## 슬라이드별 말할 포인트

### 도입 (1–3)
- **s-question** — 청중이 "또 모델 이야기"라고 예상할 지점입니다. 첫 문장에서 "이 장은 모델 고르기에 관한 장이 아니다"를 분명히 말하고 시작하세요.
- **s-flow** — 표 1은 나중에 어디쯤 왔는지 되짚을 때 다시 언급할 수 있습니다.

### §1.1 (4–11)
- **s-11-shifts** — 세 변화 중 두 번째(모델링 자유도)가 가장 반직관적입니다. "도구가 좋아지면 판별이 쉬워질 것 같지만 반대다"를 강조하세요.
- **s-11-shocks** — 네 사건을 하나씩 길게 설명하지 마세요. 원인이 다르고 결론이 같다는 구조만 남기면 됩니다.
- **s-11-vocab** — **이 회차에서 질문이 가장 많이 나올 슬라이드입니다.** 구조적 단절(언제)·국면(어떤 상태)·드리프트(모델 오류 관점)의 세 축을 손가락으로 세어 가며 말하는 편이 낫습니다. "개념 드리프트와 구조적 단절은 실체가 아니라 관점의 차이"라는 원자료의 단서를 반드시 붙이세요.
- **s-11-crisp** — 그림에서 아래로 되돌아오는 두 점선이 핵심입니다. 여섯 단계 이름을 읽는 데 시간을 쓰지 마세요.
- **s-11-failures** — 표의 다섯 실패는 §1.5의 네 오류와 짝이 됩니다. 여기서 "뒤에 독립 연구자 버전으로 다시 나온다"고 예고해 두면 §1.5가 짧아집니다.

### §1.2 (12–21)
- **s-12-workflow** — 이 회차의 중심 그림입니다. 바깥 계층 → 안쪽 루프 → 가운데 점선 → 아래 피드백 순서로 손으로 짚어 가며 설명하세요.
- **s-12-evidence** — "잘못된 질문 / 실제 질문" 대비가 이 절의 전환점입니다.
- **s-12-prespecify** — 오른쪽 열(동결하지 않으면)부터 읽는 편이 설득력이 높습니다.
- **s-12-boundary** — 증거 경계는 §1.6 확인 질문에 다시 나옵니다. "시험 횟수의 상한이 아니다"를 명확히 못 박으세요.

### §1.3 (22–27)
- **s-13-entries** — 좌우 경로가 상호 배타적이 아니라는 점을 먼저 말해야 오해가 없습니다.
- **s-13-causal** — 인과 추론을 과대 포장하지 않는 것이 이 슬라이드의 목적입니다. "의무가 아니라 렌즈"로 마무리하세요.
- **s-13-genai** — 세 실패 중 **구조적 누출**이 트레이딩에 고유합니다. 언어 모델 학습 데이터를 통한 누출 경로를 꼭 언급하세요.

### §1.4 (28–33)
- **s-14-style** — 숫자가 많습니다. 세 지표를 한꺼번에 말하지 말고 변동성 → 샤프 → 낙폭 순으로 하나씩 짚으세요.
- **s-14-aggregation** — **질문이 나올 슬라이드입니다.** "12.7%인데 왜 19.1%로도 나오나"는 실제로 물어볼 만합니다. 집계 기준(12개월 이동 평균 대 국면 직접 집계)이 다르다는 답을 준비하세요.
- **s-14-macro** — 변동성이 12–16%로 좁은데 낙폭이 10–53%로 벌어진다는 대비가 이 절의 결론입니다. 이 한 줄만 남아도 성공입니다.
- **s-14-realtime** — 선견 편향은 §1.4 전체의 위험입니다. 시간이 없으면 이 슬라이드만 남기고 s-14-tasks를 줄이세요.

### §1.5–정리 (34–40)
- **s-15-checks** — 다섯 점검을 나열하지 말고 "변동을 견디는가"라는 질문 하나로 묶어 말하세요.
- **s-16-questions** — 답을 바로 말하지 말고 Q&A로 넘기는 편이 좋습니다. 다섯 질문 모두 리포트 본문에서 답할 수 있습니다.

## 예상 질문과 답할 근거

| 질문 | 답의 근거 |
|---|---|
| 국면을 알면 타이밍에 쓸 수 있지 않나? | 98년간 267회, 약 4개월마다 전환. 잡음이 커 전술 신호로 부적합 (s-14-style) |
| 리스크 오프 변동성이 두 값으로 나오는데? | 12개월 이동 평균(12.7%)과 국면 직접 집계(19.1%)의 집계 기준 차이 (s-14-aggregation) |
| AIC가 K=6을 고르는데 왜 2상태인가? | K=6은 실루엣이 거의 0이고 1950년 이후 분할이 파편화. 목적이 해석 가능한 위험 상태라면 AIC 단독으로 고르지 않는다 (report.html#style-regimes) |
| 증거 경계가 탐색을 막는 것 아닌가? | 시험 횟수 제한이 아니라 홀드아웃의 미개봉 상태 유지. 탐색은 기록하며 자유롭게 한다 (s-12-boundary) |
| 인과 추론은 필수인가? | 워크플로는 의무화하지 않는다. 식별이 약하면 인증서가 아니라 진단 렌즈로 쓴다 (s-13-causal) |
| 생성형 AI로 만든 특성은 바로 쓸 수 있나? | 다른 산출물과 같은 검증을 통과해야 하는 후보로 취급 (s-13-genai) |

## 이 회차에서 다루지 않은 것

- `factor_regimes.ipynb`와 `macro_regimes.ipynb`를 **실행하지 않았습니다.** 슬라이드와 리포트의 수치는 모두 원자료에 인쇄된 값의 인용입니다. 실행 결과를 물으면 그렇게 답하세요.
- 국면 탐지의 구체적 모델(은닉 마르코프 모델, 변화점 검정)은 11장에서 다룹니다.
- 백테스트 하네스(16장), 비용 모델(18장), 위험·모니터링(19장), 라이브 운영(25장)은 예고만 했습니다.
