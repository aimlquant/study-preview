개체명 명확화(NED)는 문장 속 언급(mention) — 개체의 표면 표현 — 이 가리키는 대상을 지식베이스의 정확한 항목 하나로 연결하는 작업입니다.

AIML Quant교재 §8.1

표준 연결은 잘하지만, 이미 있는 관계와 경로를 놀려 둔다

scispaCy는 spaCy 위에 세워진 생물의학 전용 NLP 도구로, UMLS(통합 의학 용어 체계) 같은 표준 어휘집과 온톨로지를 내장합니다.

잘하는 일

표현을 표준 ID로

  • "고혈압", "hypertension", "혈압이 높은 병"은 서로 다른 언급
  • 세 표현이 하나의 표준 개념 ID로 연결
  • 여러 기관의 데이터를 한 기준으로 분석

저자들이 짚는 네 한계

도메인·갱신·관계

  • 생물의학 도메인 전용 설계
  • 지식베이스 확장·갱신이 어려움
  • 담긴 방대한 정보를 활용하지 못함
  • 개체 간 관계·경로를 명확화에 쓰지 못함

교재 §8.3

8.3 Ollama와 Llama 3.1 8B로 모델 준비하기 — 로컬에서 돌리는 오픈 LLM

의료 기록을 외부로 보내지 않는 로컬 실행 환경을 두 명령으로 준비한다.

03
AIML Quant교재 Listing 8.6–8.7

두 명령으로 배포하고, 쓰던 OpenAI 코드로 그대로 호출한다

Ollama는 LLM을 자기 컴퓨터에서 실행하게 해 주는 오픈소스 도구이고, Llama 3.1 8B는 80억 파라미터·최대 128K 토큰 문맥의 오픈 모델입니다.

# Listing 8.7 · OpenAI 클라이언트를 로컬로 돌리기
class LLM_Model():
    def __init__(self,
                 url='http://localhost:11434/v1',
                 key="default"):     # api_key는 자리표시자
        self.client = OpenAI(base_url=url, api_key=key)

    def generate(self, messages):
        response = self.client.chat.completions.create(
            model="llama3.1:latest",
            messages=messages,
            temperature=0,           # 매번 같은 결정적 출력
            max_tokens=4000, top_p=1,
            frequency_penalty=0, presence_penalty=0,
        )
        return response.choices[0].message.content

Listing 8.6 · 배포

문 열고 재료 들이기

  • ollama serve — 로컬 HTTP 서버를 띄운다
  • ollama pull llama3.1:latest — 모델을 내려받는다
  • 서버가 떠 있어야 왼쪽 코드가 요청을 보낸다
  • temperature=0 — 의료 코드가 실행마다 바뀌지 않게

호환의 의미 — 엔진(모델)은 바뀌어도 운전대(OpenAI Chat Completions API)는 그대로입니다. 호환되는 것은 호출 형식이지 출력 품질·속도가 아닙니다.

단계입력 → 출력실행 주체온톨로지가 주는 것

시험 규칙, 연습 문제, 모범 답안 — 퓨샷이 형식을 고정한다

퓨샷(few-shot)은 정답 예시를 프롬프트에 미리 실어 주는 기법입니다. "JSON으로 답하라"는 말보다 실제 JSON 예시가 형식 오류를 줄입니다.

# Listing 8.9 · system 지시(단순화)
system = """You are an assistant capable of
extracting named entities in the medical domain.
Your task is to extract ALL single mentions of
named entities from the text.
You must only use one of the pre-defined entities
from the following list: {named_entities}.
No other entity categories are allowed.
For each sentence, extract the named entities and
present the output in valid JSON format"""

3부 구성

규칙 · 문제 · 답안

  • system — 목록 안의 범주만 허용하는 시험 규칙
  • input — 비뇌형 모균증 위험 요인 연습 문장
  • assistant — 정답 JSON 시연. 네 라벨(Events·Disease·Qualifier value)도 전부 SNOMED 범주

효과 — 모델이 새 분류명을 지어내지 못하고, 출력 형식과 범주가 함께 고정됩니다.

라벨은 의미 범주를 거르고, ~0.80은 표기 유사도를 거른다

전문 검색(full-text search)은 인덱스로 유사 문자열을 빠르게 찾는 검색이고, 퍼지 매칭 ~0.80은 유사도 0.80 이상이면 일치로 보는 기준입니다.

두 장치

탐색 공간과 표기 흡수

  • $labels — cold가 Disease면 감기, Temperature면 온도 쪽에서 찾는다
  • ~0.80 — 오탈자·변형 표기를 흡수한다
  • 검색 재료는 Listing 8.4가 쌓은 이름·별칭 인덱스

허브 350개를 걷어 내고, 1~2홉의 방향 있는 경로만 남긴다

허브 노드는 차수(연결 수)가 매우 높아 지나치게 일반적인 노드입니다. 이를 경유하면 모든 후보가 똑같이 가까워 보여 구별력이 사라집니다. 홉은 경로가 거치는 관계 수입니다.

// Listing 8.16 · GDS로 탐지한 경로(발췌)
{ "id": 1, "path":
  "(Congenital Zika virus infection)
     -[:OCCURRENCE]->(Congenital)
     <-[:OCCURRENCE]-(Micrencephaly)" },
{ "id": 10, "path":
  "(Acrocephaly)-[:IS_A]->
     (Craniosynostosis syndrome)
     -[:IS_A]->(Congenital malformation)" }

쿼리의 세 걸음

수집 · 탐색 · 변환

  • gds.degree.stream 차수 상위 350 = 허브 수집·제외
  • allShortestPaths … *1..2 — 직접 연결 또는 중간 노드 하나
  • 방향·유형 보존 문자열 — ASSOCIATED_WITH와 CAUSES는 다른 의미

기록된 발견 — 선천성 지카 감염과 소두증은 Congenital이라는 공통 속성 노드를 사이에 두고 두 홉으로 이어집니다.

그래프 증거를 LLM이 읽는 한 문단으로 압축한다

LLM은 (A)-[:REL]->(B) 기호보다 문장을 안정적으로 해석합니다. 요약은 인지 부하(토큰 수)를 줄이되 개체명·관계 유형·방향은 보존해야 합니다 — 회의록 20쪽 대신 결정용 1쪽 요약입니다.

8.5 결론 — 온톨로지와 오픈 LLM이 서로의 빈틈을 메우다

역할 분담이 전통 도구의 한계 일부를 해소하고, 풍부한 온톨로지가 있는 도메인으로 적응할 수 있다.

AIML Quant교재 §8.5

맡는 일과 맡지 않는 일의 경계가 시스템의 실질이다

저자들의 결론은 "해소할 수 있다", "적응할 수 있다"라는 가능성 주장이며, 풍부한 온톨로지의 존재가 전제 조건입니다.

구성 요소맡는 역할맡지 않는 역할
LLM (Llama 3.1 8B)문장 이해, NER 라벨, 경로 문장화, 요약, 최종 판단후보 조회, 사실·관계의 원천, 문자 위치 계산
SNOMED + Neo4j개체·별칭·관계 저장, 전문 검색, GDS 최단 경로문장 의미 해석, 최종 선택
일반 파이썬 코드문자 위치 계산, 형식 처리, 단계 연결의미 판단

제조로의 이식 — "A200 패널 세로줄" 문장에서 HAS_PART·HAS_DEFECT 경로가 TV 제품 코드를 가리킵니다. SNOMED 자리를 제품 온톨로지가 맡으면 됩니다.

01

초기 라벨 ≠ 최종 개체

최단 경로 ≠ 인과

가깝다는 것은 관련성의 단서다. 관계 유형과 방향을 함께 읽는다.

변환·요약의 보존

ASSOCIATED_WITH를 "유발한다"로 과장하지 않고, 개체명·방향을 남긴다.

04

온톨로지 품질 = 상한

후보나 관계가 없거나 낡으면 LLM도 올바른 근거를 얻을 수 없다.

운영 감각 — $labels 필터와 ~0.80 임계값은 재현율과 정밀도의 트레이드오프로 함께 관리합니다.
